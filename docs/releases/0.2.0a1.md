# Restaurant Ops MCP 0.2.0a1

First alpha for testing a menu sales and theoretical food-cost review locally
or through an MCP-compatible assistant.

## Included

- `restaurant-ops menu.csv` prints a readable review; `--json` returns structured output.
- `restaurant-ops-mcp` runs a local stdio server with item-metrics and CSV-analysis tools.
- Input validation reports bad fields and malformed CSV rows. Expected errors
  remain readable through MCP, and a failed request does not stop the server.
- A synthetic sample menu, weekly operator guide, pilot checklist, contribution
  guide, and issue templates are included.
- Tests cover arithmetic, weighted percentages, invalid data, command-line
  behavior, and an actual MCP connection. CI also checks installation from a wheel.

## Install from source

Download and extract the release source archive, then open a terminal in its folder:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install .
restaurant-ops examples/menu.csv
```

On Windows, use `.venv\Scripts\Activate.ps1` to activate in PowerShell.
Python 3.10 or newer is required. This release uses the official MCP Python SDK
v2 (`mcp>=2.0,<3.0`). It is not a PyPI publication.

The synthetic sample returns sales of 8,152.50, ingredient costs of 2,450.50,
and contribution after ingredients of 5,702.00 across 615 units.
Follow the README to configure an MCP client with the installed server path.

## Limits

This is not production-ready accounting software. Contribution excludes labor,
rent, fees, waste, and other costs. Recipe costs are theoretical, and sales
equal supplied price times supplied units. Returns, zero-price comps, weighted
quantities, live POS imports, period comparisons, and price-change scenarios
are not supported. Currency must be consistent within a file.

For compatibility, the JSON food-cost percentage is 0.0 when no units are sold;
the warning and text report explain that the percentage is not applicable.
Amounts are rounded to two decimal places and can have rounding differences.

External adoption and measured business outcomes have not been established.
Use synthetic or anonymized examples when filing public issues.
